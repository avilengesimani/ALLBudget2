About the App

A.L.L Budgeting is an Android mobile application built using Kotlin that allows users to track expenses, set budgeting goals, monitor financial health, and analyse spending patterns through an interactive and user-friendly interface.

The application is designed to help users manage their personal finances efficiently by providing tools for recording expenses, capturing receipts, viewing spending summaries, tracking budgets, and encouraging consistent financial management through gamification features.



The Features

* Login system
* Dashboard with financial health indicator
* Add expense entries
* Expense description and amount capture
* Category management
* Date tracking for expenses
* Optional receipt photo capture using the device camera
* Expense list display on the dashboard
* Monthly spending summary
* Category-based total calculations
* Spending graph for visual expense analysis
* Budget progress tracking
* Minimum spending goal management
* Maximum spending goal management
* Financial health monitoring
* Gamification system with achievement badges
* Bronze Saver badge
* Silver Saver badge
* Gold Saver badge
* Quick navigation between application screens
* Automatic dashboard updates when new expenses are added

How to Run

1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync all project dependencies.
4. Connect an Android device or launch an emulator.
5. Build and run the application from Android Studio.

Challenges Encountered

* Navigation issues caused by missing intent configurations and click listeners.
* Layout integration challenges when adding new screens and updating XML files.
* Dependency conflicts encountered while implementing external chart libraries.
* Activity crashes resulting from incorrectly loaded layout resources.

These challenges were resolved through debugging, testing, and refinement of the application code.
